# 公式サンプルの頂点の動き（実測）

2026-10-28。公式 Cubism Core 5.3 の公開API（`Live2DCubismCore.Model` のパラメータ値の設定と `drawables.vertexPositions` の取得）で、ローカルにある公式サンプル Hiyori・Haru・Natori の頂点を測った。測定スクリプトは `tools/measure-reference.cjs`。Core・モデル・モーションは本リポジトリに入れていない。数値は響のリグの大きさを決める目安にだけ使う。

| 項目 | Hiyori | Haru | Natori | 響V3の設定 |
|---|---|---|---|---|
| 顔の向き30°：鼻の移動 / 顔幅 | 12% | 24% | 20% | 約12%（写実の顔は変形の限界が早いので控えめ） |
| 同：後ろ髪 | −2%（逆向き） | — | — | −2% |
| 上下30°：鼻の移動 / 顔幅 | 7% | 16% | 16% | 約7% |
| 口の全開：下唇の移動 / 口幅 | 40% | 26% | 8% | 約18% |
| 瞬き：上まつ毛の移動 / 目の高さ | 0.77 | 0.81 | 0.77 | 約0.8 |
| 瞬きの値と移動量 | ほぼ線形 | ほぼ線形 | ほぼ線形 | 線形＋わずかな緩急 |
| 体の向き10°：胴の移動 / 胴幅 | 11% | 13% | 12% | 約10% |

向きの変形は、顔の中心ほど大きく動き輪郭は小さく動く（近い側が縮み遠い側が広がる）。後ろ髪は逆向きに少し動く。これらの比率と傾向だけを参考にし、形状やキーの値は複製していない。
