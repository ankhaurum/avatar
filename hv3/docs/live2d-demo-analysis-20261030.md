# Live2D デモモデルの分析（体の向き・揺れもの・動きの緩急）と響V3との違い

2026-10-30。ユーザーの PC のデスクトップに置かれた Live2D 公式デモモデルの実行用ファイルを、公式 Cubism Core（公開 API、`live2dcubismcore` 5.3）で読み込んで測った。測ったのは頂点の移動量（`Model.drawables.vertexPositions`）、`physics3.json`、`motion3.json`、`cdi3.json` だけで、エディター用のプロジェクト（`.cmo3`）は開いていない。デモモデルの絵・メッシュ・モーションのファイルは本リポジトリに持ち込んでいない（描画して見比べた画像も置かない。数値と、その数値を図にしたものだけ）。ファイルは読むだけで変更していない。

分析したモデル：
- **natori_pro_t06**（natori_ja、全身、4000×7000 px、部品 176・パーツ 32・パラメータ 96、モーション 8 本、物理 11 組）— 全身モデルとして最優先
- **mao_pro**（mao_ja、ほぼ全身、5800×8400 px、部品 260・パーツ 31・パラメータ 128、モーション 7 本、物理 16 組）
- **haru**（haru_ja、半身、1024 px 系、モーション 7 本、物理 2 組）— モーションの緩急の参考

## 1. 体の向き（ParamBodyAngleX = 10 のときの頂点の移動）

移動量は、その部品の幅の半分（半幅）に対する割合。「横」は部品の幅を 10 等分して手前側の端 → 向く側の端の順、「縦」は上 → 下の順に 8 等分し、それぞれの帯の平均。

分かること：
- **円柱**：胴の中心が最も動き（中心の帯で半幅の 0.14〜0.15、胸の帯の平均で 0.17）、端はほぼ 0〜0.05。向く側の端が内へ引き込まれることは無い。手前側の面は端ほど伸び（natori のジャケット手前側 ×1.14〜1.16）、奥側は端ほど縮む（×0.89〜0.90）。
- **せん断・上下の動きは無い**：dy は全部品で 0〜3 px。
- **視差**：胸の前の飾り（襟元）は胴の面の約 1.3 倍、首は 0.5〜0.8 倍、頭は 0.3（中心線比）。
- **脚は動かさない**：natori の脚・ズボンは半幅の 0.02 以下で、裾はわずかに逆。全身の向きは上半身の円柱＋頭の添えで伝えている。
- **体の傾き（BodyAngleZ）は向きと連動しない**：BodyAngleZ 10 は腰を支点に頭が 160〜190 px 動く別の回転。

響V3（#71 まで）の同じ測り方（bodice の半幅 211 px に対する割合、BodyAngleX 10・LowerAngleX 10）：横 0.05, 0.08, 0.13, 0.18, **0.22**, 0.22, 0.14, 0.05, **−0.07, −0.16**／縦 0.08, 0.10, 0.11, 0.11, 0.10, 0.09, 0.09, 0.15。首 0.12・頭 0.10（中心の 0.5）、胸のリボン 0.22・飾り 0.29、奥側の手 **−0.51**、太もも 0.16／0.07、ブーツ 0.19／0.16。

今回（#72）：横 0.03, 0.05, 0.08, 0.10, 0.12, 0.12, 0.11, 0.09, 0.06, 0.04／縦 0.05, 0.10, 0.13, 0.13, 0.10, 0.06, 0.04, 0.04。首 0.06・頭 0.04（中心の約 0.3）、胸のリボン 0.16・飾り 0.23、奥側の手 -0.28（肩で 4° 体の後ろへ振る分）、太もも 0.04／0.04、ブーツ 0.09／0.10。

## 3. 揺れもの（physics3.json）

Cubism の物理は振り子の連鎖（Vertices：mobility 1 で減衰なし、delay は時間の倍率、acceleration は入力への感度、radius は振り子の長さ）。入力は角度（Type X ＝ 位置、Angle ＝ 角度）に重み。

| モデル | 揺れもの | 入力（重み） | 連鎖（先端） | 出力の倍率 |
|---|---|---|---|---|
| natori | 前髪 | AngleX 60・AngleZ 60・BodyAngleX 40・BodyAngleZ 40 | mobility 0.95・delay 0.9・radius 12.7 | 1.8 |
| natori | 横髪 | 同上 | 0.95・0.9・radius 18.2 | 2.0 |
| natori | 後ろ髪 | 同上 | 1.0・0.9・acceleration 1.42・radius 14.3 | 2.0 |
| natori | 前髪ふわ（上下） | AngleY 35・BodyAngleY 30・体の前後 35（反転） | 0.79・0.9・radius 11.9 | 3.0 |
| natori | ジャケットの燕尾 | BodyAngleX 100・BodyAngleZ 70・腰Z 30 | 0.95・0.8・acceleration 0.8・radius 31.9 | 1.0 |
| natori | 懐中時計の鎖 | BodyAngleX 100・BodyAngleZ 70・腰Z 30 | 2 段：0.95/1.0/r15.4 → 0.9/1.0/a0.6/r16.5 | 1.0 |
| mao | 髪（前・横・後ろ） | AngleX 60・AngleZ 60・BodyAngleX 40・BodyAngleZ 40 | 0.9〜0.95・delay 0.8・acceleration 1.1〜1.5・radius 10〜16 | 1.0 |
| mao | ローブ | BodyAngleX 100・BodyAngleZ 100 | 0.9・0.7・acceleration 1.5・radius 10 | 1.0 |
| mao | 首飾り | BodyAngleX 100・BodyAngleZ 100 | 2 段：0.8/0.6/a3/r7 → 1.0/1.0/a3/r8 | 1.0 |
| haru | 前髪・後ろ髪 | AngleX 60・AngleZ 60・BodyAngleX 40・BodyAngleZ 40 | 0.95・0.9／0.8・acceleration 1.3／1.5・radius 5／15 | 2.0 |

分かること：髪は頭の向き（60）と体の向き（40）の両方で揺れ、横髪の振り子は前髪より長い（周期で約 1.2 倍）。体に付くもの（燕尾・ローブ・鎖）は体の向きと傾きで揺れ、髪より長い振り子（ゆっくり）。響V3 は減衰ばね（`rig-eval.js` の Physics：`inputs` ＝ 定常の寄り、`kick` ＝ 速さで投げる）で、前髪 1.5 Hz・横髪 1.1 Hz・後ろ髪 0.85 Hz（周期比 1.36）、減衰 0.1〜0.12、袖・スカートは腕や体の速さで蹴る。入力の組み合わせ（頭 3：体 2）と、髪より遅い布の周期はデモモデルと同じ考え方。変更なし。

## 4. 動きの緩急（motion3.json）

すべてのキーはベジェで、ハンドルは区間の 1/3（エディターの既定の ease-in / ease-out）。

- **待機**（natori mtn_00、8 秒ループ）：AngleY ±5 を 1.7〜2.2 秒ごとに往復、BodyAngleX ±1〜2、Breath 吸う 1.8 秒・吐く 1.7 秒（周期 3.5 秒、吸う 51%）。AngleX・BodyAngleZ は 0 のまま。
- **待機**（haru idle_01、10 秒ループ）：AngleX ±14〜15 を 1〜1.6 秒で動かして 0.4 秒止める、AngleY ±10〜13、AngleZ ±14、BodyAngleX +7／−4（同じ向きに添う）、BodyAngleZ ±2。
- **うなずき**（haru m_01）：AngleY 0 → +8（0.2 秒の予備動作）→ −20（0.3 秒）→ 0（0.43 秒）、BodyAngleY が +1 → −2 → 0 で同期、目は 1.13 秒目で閉じて 1.93 秒目で開く。
- **身振り**（natori mtn_02・06）：腕の関節は 0.9〜1.2 秒で目標へ、0.2〜0.4 秒の小さな戻り、AngleY ±30 の大きな動きは 1.1 秒。

響V3：ばね（臨界減衰、頭 2.4 Hz・体 0.8 Hz）とキーフレーム（`keys()` の smoothstep）で、うなずきは 0.06 秒の予備動作 → 0.22 秒で底 → 0.52 秒で 2 回目 → 1.2 秒で収まる（2 回うなずき）。呼吸は吸う 42%・周期 3.2〜4.2 秒。待機の頭の揺らぎはノイズ（±3°）で、デモモデルの「動かして止める」形（1〜1.6 秒で動き 0.4 秒止まる）より小さく連続的。変更なし（今回は体の向きが主題）。
