# 響 V3 — 独立2Dアバター試作

**動作デモ： https://ankhaurum.github.io/avatar/**

Aifate独自2Dアバターの品質確認用プロトタイプです。**完成・正式採用・Live2D同等品質への到達を示す公開ではありません。** 21領域の現在の構成を完成形として固定せず、Identityを守りながら改善します。

## 操作と機能

「複合動作デモ」で顔・眼・口・肩・髪の動きを同時再生します。

- 浅い顔の左右・上下向きと傾き。左配置なら画面右、右配置なら画面左、中央は正面。
- 独立した視線、追従、自動/手動瞬き・片眼。
- 暫定的な感情プリセット、眉・口・身体の同時合成。
- 手動開口、音声なしの疑似発話、Web Audioの音量同期。
- 呼吸、左右肩、頭・身体に遅れて追従する髪。
- 共通人物リグと衣装packの分離。現在の実素材はスーツのみ。
- 省動作・静止表示、WebGL2が利用できない場合の静止fallback。

「音量同期を試す」は端末内の合成テスト音を実測して口を動かします。「ローカル音声を選択」で手元の音声を再生できます。音声の外部送信・マイク利用・外部TTS/API接続はありません。音声なしのデモは疑似発話と表示します。

## 公開環境の制約

WebGL2とJavaScriptを利用します。ブラウザー/端末の対応や省動作設定により静止画像へ切り替わります。音声はクリック・タップで開始し、自動再生制限、端末音量、音声形式とデコード対応に依存します。

GitHub Pagesは静的配信です。ログイン、管理画面、利用先/ロール別の設定保存、会話システム、サーバー処理はありません。既存システムとは接続していません。

大きな顔回転の見え隠れ、虹彩/白目・唇の精密分離、強い感情、母音同期には改善余地があります。瞬き・開口には局所テクスチャの重み合成も併用しています。季節衣装・帽子・任意の衣装への自動適合は未制作です。PC上の狭幅表示確認とスマホ実機の速度/発熱の検証は別です。

## 公開ファイル

HTML/CSS/JavaScript、rig.json、controls.json、wardrobe/suit.json、動作画像21領域、承認済み静止画像1枚を配置します。

承認済みの響の画像を基準に、許可された切出し・局所補修から制作しています。Live2Dのサンプル素材・SDKコード・非公開Coreは含みません。正式Identity Sheet、生成補修元、管理資料、認証情報、ローカルのパス・検証記録は公開に含めていません。

rig.jsonが共通人物、wardrobe/suit.jsonが衣装7領域と対応rig版を保持します。将来の衣装や利用先/ロール別選択は、この境界を保ちながら追加する想定です。

## ローカルで確認

静的HTTPサーバーで配信してください。Python 3がある場合、リポジトリ直下で `python -m http.server 8765 --bind 127.0.0.1` を実行し、http://127.0.0.1:8765/ を開きます。ファイルを直接開く方式ではmodule/JSONの読込み制限があります。
