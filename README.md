# 響 V3 — 独立2Dアバター試作

**動作デモ：[GitHub Pages](https://ankhaurum.github.io/avatar/)**

Aifate独自2Dアバターの品質確認用プロトタイプです。完成・正式採用・Live2D同等品質への到達を示す公開ではありません。承認済み正面画像のIdentityを基準に改善しています。

## 操作

- アバターの左右をタップすると、眼・頭・首・上半身が順に追従します。横ドラッグにも追従し、操作後は滑らかに戻ります。縦方向のページスクロールを許可します。
- 「複合動作デモ」で顔・視線・口・肩・髪を同時に動かします。操作がなくても呼吸・瞬き・小さな姿勢変化があります。
- 顔向きと視線は別々に調整できます。配置ボタンは左配置→右向き、右配置→左向き、中央→正面を設定します。
- 喜び・困り・怒り・悲しみ・驚き・思考、手動瞬き・ウインク、V2互換の10状態を選べます。
- 「音量同期を試す」は端末内の合成テスト音を実測します。「ローカル音声を選択」は端末内の音声を再生します。音声を送信せず、マイク・外部TTS/APIを使いません。音声のないデモは疑似発話です。
- 静止表示・省動作設定と、WebGL2が使えない場合の承認済み静止画像への切替に対応します。

## 再構築した方式

共通人物20領域とスーツ7領域を描画します。数は完成条件ではありません。白目・虹彩・上下まぶた、眉、上下唇・口内・歯、顔肌・首、髪の変形領域を分けました。

独自WebGL2シェーダーが、全素材の同じ座標へ同じ連続変形を適用します。浅い奥行き場で顔を投影し、首から上半身へ連続的に接続します。表情の局所変形と、独立した虹彩移動・眼の開口マスク・まぶた・唇の変形を重ねます。開眼／閉眼や閉口／開口の写真をフェードする方式を置き換えました。

入力は視線を速く、頭をその後、上半身を遅く追従させます。髪は頭・身体の速度を入力とする減衰ばねを使い、前・横・後の応答を共通の連続場に混ぜて接合のずれを抑えます。これは独自の簡易モデルで、Cubismの内部演算や物理ソルバーの再現ではありません。

三角形9,718、27描画領域。頂点・UV・索引は初期化時にGPUへ送り、毎フレームはパラメーターを更新します。画面解像度はdevicePixelRatio上限1.7を使用します。表示するCPU時間はJavaScript側の描画コマンド発行時間であり、GPU処理・端末全体の負荷ではありません。

## 技術資料と解析の限界

[公式ケイ](https://www.live2d.com/en/learn/sample/kei/)の公開JSONと、[公式CubismWebFrameworkの公開ソース](https://github.com/Live2D/CubismWebFramework/tree/d4da0aa07e47d2c1e4f5fa7ea6047861ea5e5d0b/src)を技術参考として確認しました。物理・モーション・表情・瞬き・呼吸の5ファイルをREAで静的解析しましたが、意味解析はPARTIALです。動的実行や非公開Coreの解析ではありません。

学んだ点は、入力の重み付けと分離、表情の合成、非対称な瞬きの時間、物理と描画の時間の分離、接合を保つ階層的な変形です。他社のSDKコード・モデル素材・内部係数は本リポジトリへ取り込んでいません。詳しい実施状況は[Issue #94の解析報告](https://github.com/ankhaurum/Ankhaurum-Development/issues/94#issuecomment-6310947616)に記録しています。

## 残る品質課題と公開環境の制約

浅い顔向き用の推定奥行きであり、大きな横向き・隠面・複数軸の手作業キー形状や組合せ補正は未完成です。眼瞼・頬・口角・歯の精密な造形、強い感情、写真由来の陰影と輪郭の変形には改善余地があります。音量同期は音素・母音認識ではありません。Live2D公開サンプルと同等品質と判定していません。

PC上の狭幅表示とポインター入力の確認は、スマホ実機のタッチ・速度・発熱の確認を代替しません。音声はユーザー操作で開始し、再生制限・形式・端末音量に依存します。WebGL2とJavaScriptが必要です。

衣装packは共通リグと分離していますが、実素材はスーツだけです。季節衣装・帽子・任意衣装への自動適合は未制作です。利用先・ロール別選択はデータの例であり、ログイン・管理・設定保存はありません。Twinow・HUB・V2・本番システムには接続していません。

## 配布ファイルとローカル確認

HTML/CSS/JavaScript、rig.json、controls.json、wardrobe/suit.json、動作用画像27枚、承認済み静止画像1枚を配布します。切出し・局所補修で制作した素材です。正式Identity Sheet、生成補修元、解析用の他社資料、認証情報、ローカル検証資料は含めていません。

静的HTTPサーバーで配信してください。Python 3ならリポジトリ直下で `python -m http.server 8765 --bind 127.0.0.1` を実行し、http://127.0.0.1:8765/ を開きます。ファイルの直接表示ではmodule/JSONの読込制限があります。
