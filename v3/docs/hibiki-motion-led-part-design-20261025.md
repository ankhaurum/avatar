## 3. 可動の入力と設計姿勢

既存HV3-02〜06の範囲で、頭の上下左右・傾き、胴体・肩・呼吸、左右腕の上げ下げと胸前への移動、前腕ひねり、手首、指の開閉、目・口・会話、髪と衣装の追従を対象とする。360度旋回、真横・真後ろの顔、新しい衣装や表情は追加しない。

現行 `v3/artwork/split-e/model-approved-a.json` を読み取り、次の入力群を確認した。このファイルには既存未commit変更があるため、観察した実装値を承認済みの人体可動角度や新たな完成条件に格上げしない。本設計ではID・値を変更しない。

|入力群|観察した範囲|制作へ渡す意味|
|---|---|---|
|body.x/y/lean、body.breath、chest.turn|±70 / ±40 / ±0.1、0〜1、±1|全体位置、胴体姿勢、呼吸を区別する|
|head.yaw/pitch/tilt|±0.2 / ±0.3 / ±0.13|顔向きと傾きの別入力。数値だけから完成輪郭を逆算しない|
|shoulder.*.lift、arm.*.upper/elbow|−28〜12、±1.1 / ±1.8|肩移動と上腕・肘の屈曲を分担する|
|forearm.*.twist、wrist.*.rotation/bend|±π、±0.45 / ±0.4|前腕の軸回転と手首を分離する。±πを生理的な回内外範囲の証明としない|
|finger.*.*.mcp/pip/dip|各−0.15〜0.55、左右計30スロット|連続する局所形状の入力。30スロット＝30テクスチャという分割にしない|
|gaze、blink、brow、mouth、hair.sway、cloth.sway|既存の各範囲|視線・表情・発話と二次動作を別責務にする|

親指の既存mcp/pip/dipという3スロット名を、そのまま親指の解剖学的関節名と解釈しない。制作ガイド上では母指の付け根の対立・開きと曲げを区別する。公開IDの改名や契約変更は本設計では実施しない。

制作時に描く姿勢は、中立、既存範囲の左右・上下・傾き、腕下げ／腕上げ／胸前、掌側／側面／手背側、指開閉とその接合が変わる途中姿勢。全入力の直積を試験する指示ではない。数値上の端点より、輪郭・遮蔽が入れ替わる途中姿勢を見落とさないことを優先する。

## 5. 共通の親子構造と接合ルール

下図は責務の図であり、同名ノードを全て実装する指定ではない。

```text
全体の移動・姿勢
└─ 胴体の向き・呼吸
   ├─ 胸・腰・身体面と対応衣装
   ├─ 首位置／回転 → 首局所形状 → 頭追従・顔向き
   │                                  ├─ 顔肌・顎・耳・鼻
   │                                  ├─ 左右目位置 → 開口／眼球位置／まぶた
   │                                  ├─ 眉、口位置 → 唇／口内／歯／舌
   │                                  └─ 各髪の向き → 局所揺れ
   └─ 左右肩位置 → 上腕 → 肘 → 前腕ひねり → 手首 → 掌 → 各指
       対応する袖・袖口は同じ骨格運動に追従し、布の局所形状は別に持つ
```

首・頭を独立に調整する際、顔向きが首の端点と二重に合成されないよう責務を分ける。図中の「首局所形状→頭追従」は首の取付位置を伝える関係であり、首を潰した分だけ顔全体を潰す指定ではない。

接合は二種類に分ける。同じ連続表面（肘の皮膚・袖の縫い目など）は一致する接合位置と局所形状でつなぐ。Cubismでは必要箇所にグルーを使えるが、影や輪郭が二重にならないことが前提。別物体の遮蔽（袖口と手首、髪と顔、襟と首）は頂点を貼り付けず、十分な裏面と前後関係で成立させる。身体と衣装を同じ画像へ結合しない。[S3/S4]

原画Aの肩幅、肘・手首の位置、掌幅・各指の長さを制作ガイドの基準とする。左右で見え方や形が違うため、反転コピーだけで左右完成とはしない。これらのガイドは次の制作工程で採寸するが、新たな寸法・体型を決めるものではない。

## 6. 隠れ面の範囲を決める方法

一律に「何px広げる」「何％描き足す」とは決めない。対象の既存姿勢で、隣接部品が動いて覆いが外れる範囲を原画座標へ戻し、その範囲を含む完全な素材面を設計する。通常の補間で境界が少し動いても切れない重なりを持たせる。可視輪郭は原画に合わせ、余白は隠れる側へ取る。

例：首では顔を上向きにしたときの顎下と、首を横へ倒したときの反対側の襟奥をともに支える。肩では腕を上げたときの脇だけでなく胸前へ寄せたときの袖山も支える。掌では指を開いた指股と、曲げたときの関節裏の両方を用意する。後髪は顔の輪郭が動いて現れる側頭部を含む連続面とし、正面の見えている帯だけを素材にしない。

濃い接触影を可動する別物体へ焼き込むと影が取り残される。必要な影は対応する物体または独立した影面に担当させる。写真調の自然な陰影を全て消す指示ではない。

## 7. 物理演算と主動作を分ける

物理演算を入れる前に、髪・裾・タイなどの揺れ端点を手動パラメータで動かし、根元が接続し、隠面が足り、輪郭が成立する設計とする。頭・胴・腕の主動作は姿勢制御が担当し、物理はその後の遅れ・戻りだけを担当する。[S5]

短いボブへ長髪の多段振り子を無条件に持ち込まない。根元を固定し、別の位相が必要な毛束だけ揺れを分ける。衣装は固定点（襟・袖口・結び目）と自由端（裾・タイ下部）を区別する。まばたき・発話・指の目標姿勢を物理へ任せない。

物理の範囲は、用意した形状と遮蔽が成立する範囲内に収める。強い揺れで素材不足を見えにくくしたり、揺れを止めて必要な可動を省略したりしない。具体的な係数は素材・キー形状完成後の調整事項であり、今回新しい固定値を決めない。

## 8. 設計から制作へ渡す内容と限界

各部品には「原画基準・親・担当する動き・接合先・前後関係・必要な隠面」を添える。制作では単体の完全形状、原画Aへの中立組立、関係する端点と途中姿勢を順に確認する。全組合せの過剰な試験、固定のレイヤー枚数、頂点数、角度拡張は追加しない。

設計レビューでは以下を区別した。

- 説明できるもの：各部位の分割理由、親子関係、変形と遮蔽の責務、隠面の必要範囲、物理を後に置く理由。表の全対象に記載した。
- 制作で確かめるもの：実際のピクセル境界、メッシュの頂点配置、接合の重み、向きごとの描画順キー、写真調の陰影の連続性。設計だけで実証済みとはしない。
- 残る技術上の注意：写真調の高角度顔と30指関節は、参考モデルの枚数やPose差分で保証されない。既存入力契約と人体の可動の対応は制作時に確認し、仕様変更が必要になれば別途判断する。未検証の既存数値を理由に今この段階で仕様を変更しない。
