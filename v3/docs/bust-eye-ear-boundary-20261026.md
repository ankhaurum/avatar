# バストアップ正本: 眼球・耳の接合修正 v7

首・髪分離済みv5に、虹彩とまぶたの画素分離、隠れた虹彩の補完位置修正、耳内側の原画接合を追加したレビューPSD。元のv5とv6を保全し、別名保存した。

## 確認

- 虹彩: 両眼の補完レイヤーの座標逸脱を除外。まぶた由来の接触画素を別レイヤーへ分離。
- 分離だけの正面RGBA差分は0。補完をなじませた後は296画素・最大11階調の変更、alpha差分0。Rの原画差平均0.952051→0.847980、L0.714096→0.697400。30階調超は各5画素のまま。
- 耳: 原画同位置の接合補修266画素。耳以外とalphaの変更0。原画差平均0.709254→0.429342、30階調超92→26画素。
- v7保存・再読込のRGBA差分0。PSD SHA256: 3858ed658c683b904f94a63aa75f79fcbb8d6dd511d4e14fff9dd9d7077c3626。
- 明暗背景で全体を目視。鼻・口と顔輪郭の形状は今回の眼・耳修正で変更していない。

## 保存停止の修正

追加した深い入れ子グループが、PhotoshopのCS6以前向け互換性通知を出して保存を停止していた。Computer Useで実ダイアログを確認しEnterで解除。その後、補完専用の1子グループをマスク込みで統合し階層を浅くした。v7は通知待ちなしで保存でき、表示差分0。アプリ設定の恒久変更・強制終了はしていない。これはHTTP400 Bad Requestとは別問題。
