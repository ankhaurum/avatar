# 響V3：構造設計に基づく独立髪素材M

2026-10-25 / Codex・実装エージェント / 既存HV3-03

## 制作したもの

[構造設計](hibiki-motion-led-part-design-20261025.md)の後頭部被覆と左右横髪の役割に基づき、後髪・キャラクター右横髪（画面左）・キャラクター左横髪（画面右）の3素材を、根元から毛先まで独立した全体形状として制作した。

新規PSD `v3/artwork/split-e/hibiki-v3-independent-hair-m.psd` は3つの編集可能な素材レイヤーと、非表示・ロック済みの承認原画A参照を持つ。原画A、J版、K/L版、既存未commit変更を上書きしていない。新しい素材をJ版や公開モデルへ採用した意味ではない。

|素材|構造設計との対応|制作内容と限界|
|---|---|---|
|後髪|Keiの顔裏まで覆う後髪とHaruの頭部追従／局所揺れの役割|中央に顔形の穴がない連続面。前髪・耳・首・顔を含まない。高角度で必要な被覆はCubism検証前。|
|右横髪|頭部に隠れる根元と局所的に揺れる毛先を分担|隠れる上端から毛先まで一体の素材。顔・耳・背景を含まない。根元の厚みは前髪下での組立確認が必要。|
|左横髪|右とは独立した形・制御・遮蔽|反転コピーではなく別の素材として生成。右横髪を材質参照に使い、左右の表面の色調を揃えた。原画固有の非対称形状との最終照合は未了。|

左右・後髪の3枚で髪全体が完成したとは扱わない。内側毛束、前髪、襟足、髪影などは設計上の役割に応じて別途制作する。固定の枚数へ合わせる制作ではない。

## 使用経路

- imagegen組込みツールで、独立素材を全体として描き起こした。See-Through・自動分割・既存出力の欠損修繕は使用していない。
- 右横髪は原画Aを目視した形状・色・質感の記述で生成。左横髪と後髪はその新規素材を材質参照に生成した。原画Aと同一画素の切抜きではない。
- Photoshop直接COM/JSXで透明余白のトリム、原画座標へ配置するためのサイズ調整、独立レイヤーへの格納を行った。穴埋め、継ぎ足し、背景除去による修繕はしていない。
- フル解像度の生成原本と配置用PNGの両方を保全。配置用は原画1024×1536に合わせた候補であり、生成原本の解像度を失わない。
- Photoshopから白背景・暗背景の単体一覧を実出力。生成ツールのプレビューだけで品質を判定しなかった。

## 不採用にしたもの

最初の左横髪候補は背景状の青いにじみがあり不採用。次は補修せず、適切な材質参照を用いて独立素材全体を新しく制作した。前髪候補は原画より厚く外側へ張るため不採用。これらを制作PSDへ混ぜず、元出力はローカルの生成履歴に保全した。

前ターンのL比較PSDには旧素材の輪郭と肌境界の欠陥が残っていた。M版はその組立を修繕する土台とせず、新規素材と原画参照だけを持つ。顔・体型を素材へ合わせて改変していない。

## 確認したこと

- 白／暗背景で3素材に顔・耳・肌・衣装が混入していないこと、根元から毛先まで連続していることを目視確認。
- 3PNGのRGBA、非空、透過と実描画寸法を確認。alphaの数値だけを品質合格にはしていない。
- 保存したM PSDをディスクから再読込みし、3素材レイヤーと非表示・ロック済み参照を確認。保存前後の合成RGBAは完全一致。
- 原画AのSHA-256は `a62d7badad8801b9cd91994436eaf0ad77e4ef09401b84cea3d9a51d3543e5cf` と一致。J版PSDも既存記録のハッシュと一致。
- 配置マニフェストではPNGキャンバス寸法、アルファ境界、Photoshop上のレイヤー境界を区別し、PNGの原点を計算して記載した。

## 未達と次の制作対象

新素材は原画の可視髪より暗めで、毛先の流れにも違いがある。単体の構造が成立することと、響の髪として最終採用できることは区別する。前髪との重なり・全体シルエット・色調の原画照合、内外の毛束と襟足、髪影、Cubismの向き／揺れ検証は未達。原画Aのファイル不変は、新しい組立のIdentityの検証を代替しない。

顔・首・身体・衣装・両腕両手の新規独立素材は今回の3素材に含まれない。既存の素材が全て新設計を満たしたとも扱わない。HV3-03全体、独自V3への反映、Human Acceptanceは未完了。公開プレビュー・Twinow/HUB/V2/#38/本番/Driveは変更していない。

制作JSX、使用プロンプト、配置、ハッシュ、再読込み確認は `v3/evidence/material-redesign-20261025/m-*` に記録する。
