# バストアップ正本: 首・髪・顎の素材分離

首に残った重複顎と毛束を分離し、顎の接触影を顔、首の毛束と影を髪、肌を首へ配置。襟の接合は正本の同位置画素で連続させた。正面の目・鼻・口のRGBA差分0。顔や唇の座標変更はない。

検査PSD v5は候補からのRGBA差分0、保存再読込のRGBA差分0。顔の正本との差の平均は0.508078から0.449987へ、首は2.931301から2.579157へ減少。顔30階調超78画素、首2690画素は残り、原画一致・完成の証明ではない。alpha変更14画素。

首の肌と毛束は正本の色を再合成できるように分離。衣服色の除外マスクは修正版を採用し、旧破損TGAは不採用。ExtendScriptのゼロバイト欠落を修正して独立比較0差分を確認。

未達: 虹彩単体の上縁にまぶた由来の暗い帯が残る。既存の隠れた虹彩補完レイヤーには座標逸脱を発見。修正試作は別文書に保留し、このPSDへ採用していない。耳・口内・全身・可動時被覆も完了していない。Cubism未取り込み、モデル出力・公開なし。
