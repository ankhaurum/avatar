# HV3-04/05 指節の厚みキー（r34候補）

PSDはr33を維持。モデルは `model-fold-r34.json`。

XY形状に加えて、キーごとに任意の `depthDelta`（頂点数と同数、原画px）を記述できる。通常の形状キーと同じ軸補間を使い、表情等のXY変形後・局所立体関節の変換前に適用する。中立キーは0。未指定時は従来どおり。有限値・頂点数・surface必須を検証し、不正データは拒否する。

`tools/author-finger-folds.mjs` で左右各5指の3関節、甲掌それぞれに60キー群を制作。掌側の折れ込みと周辺のふくらみ、甲側の小さなふくらみを別形状として記述する。値は編集可能な制作候補であり、解剖学的正確さや完成品質の保証ではない。PSDや公式顔の変更なし。

制作画面の「局所厚みの形状キー」で、パーツ・関節・正確なキー姿勢・頂点番号を選び、補正値を読取り／変更できる。途中姿勢は編集対象としない。Undoと既存JSON保存・読込に含める。

## 確認

- r34を制作画面へ読み込み、右人差し指のMCP .8 / PIP 1 / DIP .45 と前腕ひねり1.8を実描画確認。`right-fold-r34.jpg`。
- 左人差し指のPIP .7と前腕ひねり-1.8を確認。甲掌の接続は維持したが、皮膚陰影の仕上げは未完了。
- 左掌側人差し指、PIPキー .7、頂点148の厚み値 `.8633853493242668` を `1.2` へ変更し読取り、Undoで元値へ復帰。
- 検証用に再度1.2へ変更→UIのJSON保存→実ファイルで1.2を確認→UIで再読込→同じパーツ・キー・頂点の1.2を読取り確認。`depth-key-roundtrip-r34.jpg`。この検証用の1頂点変更は正式モデルへ採用しない。
- ブラウザーのdownload通知はタイムアウトしたが、実際にはDownloadsへ保存されていた。ファイル内容と再読込で確認し、通知成功と実ファイル生成を区別した。
- 関連回帰22テスト通過（厚みの補間順序、編集反映、不正データ拒否を含む）。テストだけでは視覚的完成とは判断しない。
