# 響V3 — 原画Aの衣装隠面・独立素材

対象: Ankhaurum-Development #94 / HV3-03 #98、次工程 HV3-04 #99。実装PR: avatar #27。

承認原画は `../hibiki-static-a.png`（d8e3a9c）。原画ファイル、17c3f54の分割D PSD、14部品PNGを保全したまま、編集用PSD `hibiki-v3-wardrobe-e.psd` を制作した。顔・髪・手を再生成・拡縮・鏡像化していない。画像生成サービスは使用していない。

## 制作した素材

- 身体接合: 衣装の下に必要な首元、左右腕、胴体の塗り足し。PSDでは身体側の独立レイヤー。露出した身体を新しく生成したものではない。
- シャツ: ジャケット下の本体・左右袖・ネクタイ下の前立て・ボタン・襟の裏。承認原画の布地をPhotoshopで補完・調色し、元ジャケットの縁取り・装飾・ポケット・ボタンを除去した。襟・前立て等は編集可能。
- 下衣: 元の白いプリーツ素材を基準に腰までを補完。腰の重なりを含む一つの下衣素材として取り外せる。
- 所有修正: 襟脇・青い裾・裾の下地をジャケット側へ移した。手・脚に混入した下衣を衣装側へ戻し、下衣から複製された肌を除去。原画のRGBと透明度を保持して部品間だけを移管した。
- 髪先: 初期分割でジャケット側に入っていた原画の毛先を身体側へ戻した。身体の可視部分は衣装より前に描画する。

`parts/` のPNGは共通1024×1536座標。PSDは `psd-layer-map.json` にレイヤーとレイヤーカンプを記録した。`material-manifest.json` に由来・寸法・SHA・組立順を記録する。元原画の参照レイヤーは非表示で、衣装の組立には使用しない。制作途中の単色シャツ案はPSDから除き、必要な前立て・ボタンだけを完成素材へ引き継いだ。

## 確認する状態

PSDのレイヤーカンプと `index.html` で以下を確認できる。

1. 承認原画の通常衣装。
2. ジャケットを外したシャツ＋ネクタイ。
3. ジャケットとネクタイを外したシャツ。
4. 元のジャケットを着たままネクタイを外した状態。
5. ジャケット・シャツ・ネクタイを保ち、下衣だけを腰まで補完した独立素材へ交換。

衣装を非表示にして原画を表示し続ける処理や、メッシュ・動作による欠損補正はない。確認ページも独立した素材PNGを描画順に重ねている。

## 検証

`verify-wardrobe-materials.py` が原画SHA、分割DのPSD・14部品SHA、各状態のPSD再読込み、PNGのみの再合成を比較する。顔・髪の主要領域と実際の手素材について、衣装の切替前後を原画と比較する。旧手レイヤーに含まれていた白い下衣の画素を保護対象の肌と誤認しないよう、所有修正後の手素材を用い、元の肌を失っていないことも検査する。

双方alpha=0のRGBはPhotoshopの保存時に正規化されるため、RGBの一致対象は可視画素。alphaは全画素で比較する。独立グループを書き出して再合成すると、半透明の境界が1階調だけ丸められることがあるため、実際の差分値を記録する。通常衣装と原画の比較にはこの許容を適用しない。

布地の補完中に検出した問題は、RGBチャンネルへ戻さず選択用チャンネルを編集したことによる切り抜き不良、素材の所有混入、選択マップに原画の半透明が残ったことによるalpha差だった。対象チャンネルを明示し、所有マップを二値化してから元14部品を再移管して修正した。透明度を一律255へ変えて一致を装う修正ではない。
